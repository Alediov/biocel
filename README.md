# BioCel

App de estudo de Biologia Celular para a turma de Odontologia da UNIOESTE (monitoria): trilhas de lições do
ciclo celular e da meiose, a leitura dos capítulos da prova (só para quem entra na turma), ranking e progresso
salvo com login pelo Google.

Este repositório só tem o app montado. Ele é gerado por `tools/biocel/montar.py` no repositório privado do
monitor; não edite aqui à mão. O texto do livro não fica aqui.
